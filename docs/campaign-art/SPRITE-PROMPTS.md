# Campaign sprite assets

Generated with the built-in image generator. WebP quality 88 retains the original alpha channel. These are original game assets, not extracted game art.

All three atlases use four equal columns and two equal rows. Final dimensions are 1774 × 887 pixels. Cell indices are row-major, starting at zero. `dist/assets/campaign/atlas-bounds.json` records source rectangles for content alpha greater than 100/255, excluding faint generation fringe outside the sprites. The source image alpha itself is preserved.

Boss registration uses `anchorX` and `anchorY` relative to each cropped image. Draw both frames of a pair with one scale derived from `pairW` and `pairH`, at the same anchor; do not stretch each frame independently. For floating bosses the bottom anchor is a stable sprite registration reference, not a ground contact. Terrain `lipY` is an absolute atlas coordinate at the first almost fully opaque horizontal upper surface.
